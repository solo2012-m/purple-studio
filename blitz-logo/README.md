# Purple Blitz — векторная реконструкция логотипа

Реконструкция по утверждённому референсу: объёмные контуры букв и электрическая Z.

## Файлы
- reference.png — исходный референс владельца.
- logo.svg / logo.png — чистый логотип на прозрачном фоне (PNG 2775 px).
- scene.svg — логотип с разрядами (как в референсе).
- purple.svg, blit.svg, z.svg, discharges.svg, glow.svg — элементы по отдельности.
- index.html + animation.js — страница предпросмотра с анимацией появления (один проход, ~3,2 с).
- build.py — генератор контуров; make_preview.py — сборка страницы.

## Анимация
Появление надписи → короткий удар разрядов → формирование Z → затухание. Без бесконечного цикла. При «уменьшить движение» показывается статичный финал.

## Ограничения
Векторные контуры нарисованы вручную по референсу, это не оригинальный файл автора референса. Проверка прав и уникальности названия не выполнялась. Шрифты не используются — все буквы в контурах.
