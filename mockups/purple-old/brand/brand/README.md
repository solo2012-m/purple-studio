# Purple Blitz — бренд-пакет
Выбор дизайнера: концепция 1 Quiet Power, предварительный финал до утверждения владельцем.
## Файлы
logo.svg / logo.png — тёмная надпись, прозрачный фон.
logo-dark.svg / logo-dark.png — светлая надпись, прозрачный фон.
logo-animated.svg — светлая надпись, SVG + CSS анимация 3,2 секунды, один проход.
icon.svg, icon-16/32/48/180/512.png, favicon.ico — знак Z.
concept-1/2/3-light/dark.svg — три композиции; concept-1/2/3-icon.svg — знаки.
## Встраивание
На тёмном фоне: <img src="brand/logo-animated.svg" alt="Purple Blitz" width="500">
Статичный: <img src="brand/logo-dark.svg" alt="Purple Blitz" width="240">
Favicon: <link rel="icon" href="brand/favicon.ico">
Анимация: появление текста → короткая молния → Z → фиксация. prefers-reduced-motion отключает движение. Не использовать как блокирующий загрузочный экран.
## Палитра
Electric Purple #9945FF, Ink #0B0911, Cloud #F7F4FF, Afterglow #DAB7FF.
## Типографика
DejaVu Sans Bold и Bold Oblique, текст преобразован в контуры. Лицензия приложена.
Для сайта рекомендуются Manrope, Inter, IBM Plex Sans (не включены).
## Использование
Минимальная ширина полного логотипа 180 px. Ниже — Z. Поле вокруг: минимум половина высоты Z. Не искажать пропорции.
Название и юридическая уникальность не проверены. Дизайн нарисован самостоятельно; отсутствие сходства со всеми существующими знаками не гарантируется.
